# 🎨 Blender Projects

A collection of my 3D models created using Blender.
This repository includes various assets such as weapons, props, and more — all provided in both `.fbx` and `.blend` formats.

---

## 📦 Project Content

Each project folder may include:

* `.blend` → Original Blender file (editable)
* `.fbx` → Exported file (game-ready / compatible)
* Textures (if available)
